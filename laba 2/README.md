# Лабораторна 2: вимоги та сценарії Codewars

Ця папка містить структуровані вимоги, сценарії та Use Case-модель. Вона
спирається на сутності `User`, `Rank`, `Kata`, `Language` і `Attempt` з
лабораторної №1, що знаходиться в корені репозиторію.

## Структура

- [`spec.md`](spec.md) — межі лабораторної та критерії прийняття.
- [`requirements.md`](requirements.md) — EARS-вимоги, user stories і Gherkin.
- [`traceability.md`](traceability.md) — матриця трасування.
- [`model/use-case-diagram.puml`](model/use-case-diagram.puml) — джерело діаграми.
- [`model/use-case-diagram.svg`](model/use-case-diagram.svg) — рендер.
- [`audit/requirements-discrepancies.md`](audit/requirements-discrepancies.md) — аудит.
- [`adr/0002-requirements-and-use-case-boundaries.md`](adr/0002-requirements-and-use-case-boundaries.md) — ADR.
- [`DEFENSE.md`](DEFENSE.md) — точка входу для рев'ю.

Читати лабораторну №2 слід від [`spec.md`](spec.md) до вимог, сценаріїв,
трасування, Use Case-рендера та [`DEFENSE.md`](DEFENSE.md).
