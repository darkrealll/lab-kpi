# Лабораторні Codewars

Цей репозиторій містить послідовні лабораторні роботи для платформи
Codewars. Лабораторна №1 описує модель даних, а лабораторна №2 — вимоги та
сценарії взаємодії.

## Лабораторна 1

Файли ER-моделі знаходяться в корені репозиторію:

- [`spec.md`](spec.md) — межі домену та критерії прийняття.
- [`model/er-diagram.mmd`](model/er-diagram.mmd) — джерело ER-моделі Mermaid.
- [`model/er-diagram.svg`](model/er-diagram.svg) — рендер діаграми.
- [`audit/discrepancies.md`](audit/discrepancies.md) — аудит узгодженості.
- [`adr/0001-attempt-as-associative-entity.md`](adr/0001-attempt-as-associative-entity.md) — ключове рішення.
- [`DEFENSE.md`](DEFENSE.md) — точка входу для рев'ю.
